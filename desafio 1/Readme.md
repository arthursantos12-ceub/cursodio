# 💳 Identificador de Bandeira de Cartão de Crédito com IA & Regex

Projeto desenvolvido como parte do desafio da **DIO** para criar uma aplicação em Python capaz de identificar a bandeira de um cartão de crédito utilizando expressões regulares (`regex`), com o auxílio do **GitHub Copilot** como assistente de desenvolvimento.

---

## 🚀 Tecnologias Utilizadas

* **Python 3**
* **Expressões Regulares (Módulo `re`)**
* **GitHub Copilot** (Assistência de código e produtividade)
* **Git & GitHub** (Versionamento)

---

## 🎯 Funcionalidades

O programa valida e identifica as seguintes bandeiras com base nos padrões numéricos oficiais:
* **Visa**
* **MasterCard**
* **American Express (Amex)**
* **Discover**
* **Elo** (Padrão nacional brasileiro)
